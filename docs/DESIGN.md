# 设计系统

CodePool 使用“工程控制台”视觉语言：深墨色背景、荧光绿状态色、等宽字体标签和清晰的边界线。视觉应表达工具感与可信度，不使用大面积科技紫渐变。

## Web

- 主背景 `#0B0F19`，面板 `#121823`，边界 `#253042`。
- 主文本 `#F5F7FB`，次文本 `#8B95A7`。
- 品牌/安全状态 `#9DFB70`；危险操作 `#FF7E79`。
- 标题紧凑，数据和标签使用等宽字体；动效只用于反馈和状态。
- 管理端永远不展示内容正文、TOTP 密钥或当前动态码。

## 微信小程序

- 保持微信原生交互和浅色内容卡片，导航使用深墨色，选中态使用绿色。
- 首页第一屏优先展示团队切换、搜索和当前验证码。
- 敏感值默认按需读取；复制、分享、删除必须提供明确反馈。
- 首页以“内容池”为主信息架构，同时提供代码片段、临时验证码和 TOTP 快捷入口。
