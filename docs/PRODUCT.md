# CodePool 产品定义

## 定位

CodePool 是小团队的安全共享池，解决“不适合发在群里、但需要高频协作”的短内容：部署命令、
代码片段、动态验证码、测试口令、临时密文和交接备注。

核心承诺：**取用足够快，默认不过度暴露，权限边界清楚，每个关键动作可以追溯。**

## 内容模型

| 类型 | 典型场景 | 默认展示策略 |
| --- | --- | --- |
| `snippet` | Shell、SQL、配置片段 | 列表仅元数据，详情显式读取 |
| `totp` | 云平台和研发工具 2FA | 默认遮罩，按需计算，不返回密钥 |
| `code` | 测试短信码、兑换码 | 支持过期时间 |
| `secret` | 临时 Token、只读凭据 | 显式读取并记审计 |
| `note` | 交接说明、操作提示 | 显式读取并记审计 |

## 成员角色

- `owner`：团队所有者，负责所有权和完整治理。
- `admin`：管理成员、动态码、内容、邀请与分享。
- `member`：创建普通内容、按权限读取并创建短期分享。
- `guest`：只读成员，可设置成员关系到期时间。

运营管理员不属于团队 RBAC，不读取正文，只处理账号、团队、内容元数据、访问入口、审计、
运营策略与隐私请求。

## 小程序核心旅程

1. 阅读并同意政策后使用微信登录，首次登录创建默认团队。
2. 创建团队或接受一次性邀请，按角色显示可执行操作。
3. 添加普通内容、手工导入 TOTP 或扫描 `otpauth://` 二维码。
4. 在列表搜索筛选；动态码和密文默认遮罩，显式点击后短时显示。
5. 编辑、删除、复制或生成限时限次分享；外部接收者先预览，再确认领取。
6. 查看团队成员、邀请状态和脱敏审计记录。
7. 在个人页管理本地安全、查看政策、退出登录或提交/撤回注销申请。

所有页面提供加载、空数据、错误、离线、重复提交和下拉刷新状态。

## 运营后台

- 运营总览：用户、团队、内容、分享、14 天活跃趋势、内容构成与待处理事项。
- 团队管理：搜索分页、新建、详情、成员角色、所有权转移、停用恢复。
- 用户管理：搜索分页、详情、状态、团队、活动、停用并强退全部设备。
- 内容治理：只读元数据、类型/状态筛选、停用恢复、永久删除。
- 分享与邀请：生命周期、领取次数、创建者、到期与人工撤销。
- 安全审计：操作、人员、团队、时间筛选和 CSV 导出。
- 注销申请：批准、驳回、团队交接校验和不可逆匿名化完成。
- 系统设置：运营开关、公告、配额、有效期、数据库与上线安全检查。

## 明确边界

- 不是代码托管平台，也不是个人完整密码管理器。
- 不抓取短信、邮箱或通讯录。
- 不在运营后台提供正文、TOTP 密钥或密文批量导出。
- 当前不包含套餐、支付、订单和发票；若“商用”需要收费，需要单独定义商业模式。
- 正式运营仍依赖运营主体、微信平台配置、备案、法务文本、客服和基础设施备份。
