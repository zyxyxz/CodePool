# CodePool 微信小程序

原生微信小程序，不依赖 npm 构建链。用微信开发者工具直接导入本目录。

## 生产配置

- API 默认地址：`https://codepool.apps.aisp24.com`
- 微信公众平台的 `request` 与 `downloadFile` 合法域名必须包含 `https://codepool.apps.aisp24.com`
- 服务端必须配置与本项目 AppID 匹配的 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`
- 正式体验版和正式版必须保持“合法域名校验”开启
- 本地联调覆盖值 `CODEPOOL_API_BASE_URL` 只用于开发者工具，提审前需要清除

## 提审前阻塞清单

1. 在小程序后台配置真实运营主体、隐私保护指引和用户信息处理清单，至少声明微信头像、昵称以及选中的照片信息。
2. 配置服务端 `CODEPOOL_OPERATOR_NAME` 与客服邮箱；小程序法律页会动态下发主体信息，随后完成法务审核。
3. 验证个人页的账号注销申请、撤回及后台运营处理闭环。
4. 配置服务端微信登录参数，并分别使用开发版、体验版和正式版 AppID 验证登录。
5. 验证新用户、访客、成员、管理员和所有者五类权限路径。
6. 验证动态码不会在列表自动读取，切后台后立即遮挡；分享必须先预览、再确认领取。
   小程序本地草稿只保存标题等元数据，不缓存正文、密文或 TOTP 密钥。
7. 使用弱网、离线、401、403、410、429 和服务异常场景完成真机回归。
8. 确认代码池数据库已备份、加密主密钥可恢复、审计与注销工单有运营负责人。

## 空间主题

团队已有的六种主题色映射为鼠尾草、雾霭蓝、香芋紫、蔷薇粉、杏仁桃和薄荷青配色。
`utils/theme.js` 统一生成页面 CSS 变量及原生导航栏、下拉背景、底栏颜色，保留服务端原有颜色标识。
首页切换空间时同步换色并清空旧空间内容，过时的列表和动态码请求不会覆盖新空间。
主题色按空间标识缓存；返回首页及重新打开应用时恢复，退出登录时清除。

修改配色后，在仓库根目录运行 `node scripts/generate-theme-icons.mjs` 更新六套底栏选中图标。

## 发布检查

```bash
npm run check:miniapp
```

随后使用微信开发者工具的“代码质量”与“体验评分”检查，并在 iOS、Android 至少各一台真机完成扫码、剪贴板、转发深链、下拉刷新和后台遮挡测试。
